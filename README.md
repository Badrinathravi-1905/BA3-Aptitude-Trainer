# BA3 Aptitude Trainer

**BA3** · *Build speed. Build accuracy. Build recall.*

A mobile-first PWA for competitive-exam prep: alphabet values (forward and reverse), tables 2–28, squares 1–30 and cubes 1–20, trained through MCQ active recall with spaced repetition.

> Concept, requirements and product direction by Badri (BA3). Built using AI-assisted development.

## Features
Quick, Focus, Weak-areas and Timed practice · server-validated answers · per-device anonymous users (UUID in localStorage) · spaced repetition · progress dashboard · installable PWA.

## Stack and architecture
React + Vite + Tailwind (frontend) · FastAPI + SQLAlchemy + Pydantic (backend) · SQLite in dev, PostgreSQL in prod (`DATABASE_URL`).
Questions are generated by code. Each question id is an HMAC-signed token of its parameters; `/api/attempt` verifies the token and recomputes the correct answer server-side. The correct answer is never sent to the browser before the user answers.

## Local setup (Windows 10/11, PowerShell)
```powershell
cd backend
py -3.13 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
python -m pytest
uvicorn app.main:app --reload --port 8000
```
If activation is blocked: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`. Tables are created automatically at startup.

New terminal:
```powershell
cd frontend
npm install
copy .env.example .env
npm run dev        # http://localhost:5173 (proxies /api to the backend)
npm run build      # production build in frontend/dist
```

## Environment variables
| File | Variable | Meaning |
|---|---|---|
| backend/.env | `DATABASE_URL` | SQLite locally; `postgresql://…` in production |
| backend/.env | `ALLOWED_ORIGINS` | Comma-separated frontend URLs allowed by CORS |
| backend/.env | `SECRET_KEY` | Signs question tokens. Use a long random value in production |
| frontend/.env | `VITE_API_URL` | Public backend URL in production (blank in dev) |
| frontend/.env | `DEV_API_TARGET` | Dev-only proxy target |

## API
Interactive docs at `/docs`. All calls except `/api/health` need header `X-User-Id: <uuid>`.
`GET /api/health` · `POST /api/users` · `GET /api/question?mode=&topic=&exclude=` · `POST /api/attempt` · `POST /api/session/start` · `POST /api/session/end` · `GET /api/stats` (alias `/api/progress`) · `GET /api/weak-areas`

## Deployment (free tier)
1. Push to GitHub (`git init`, `git add .`, `git commit -m "BA3 Aptitude Trainer"`, add remote, `git push`).
2. **Backend on Render**: new Web Service, root `backend`, build `pip install -r requirements.txt`, start `uvicorn app.main:app --host 0.0.0.0 --port $PORT`, health check `/api/health`. Add a free PostgreSQL database and set `DATABASE_URL`, `SECRET_KEY`, and `ALLOWED_ORIGINS=https://<your-frontend-url>`.
3. **Frontend on Vercel or Netlify**: root `frontend`, build `npm run build`, output `dist`, env `VITE_API_URL=https://<your-render-url>`. Redeploy after setting it.
4. Open the HTTPS URL on Android → browser menu → **Add to Home screen**. Share the link on WhatsApp.

Free Render services sleep when idle, so the first request can take about 30 seconds.
